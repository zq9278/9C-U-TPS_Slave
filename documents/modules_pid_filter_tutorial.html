PID 与目标窗口滤波模块使用教程

适用于 Modules/Pid 与 Modules/Filter，接口风格为纯 C，使用结构体句柄模拟对象。

1. 模块定位 2. PID 文件与接口 3. PID 参数说明 4. PID 使用示例 5. 滤波模块接口 6. 滤波使用示例 7. 在控制任务中集成 8. 调参建议

1. 模块定位

这两个模块放在 Modules 层，目标是让压力控制、温控、传感器采样等不同业务都能复用同一套基础算法。

模块 路径 用途
PID 控制器 Modules/Pid/pid_controller.h/.c 支持多个 PID 实例，各自保存积分、上一拍误差、上一拍测量值、微分滤波状态。
目标窗口滤波器 Modules/Filter/target_window_filter.h/.c 在一个采样窗口中选择最接近目标值的样本，适合剔除瞬态毛刺或寻找稳定段代表值。
设计方式是“面向对象思维，C 语言实现”：每个对象都是一个结构体实例，函数第一个参数传入该实例指针。

2. PID 文件与接口

头文件：Modules/Pid/pid_controller.h

源文件：Modules/Pid/pid_controller.c

核心结构体

结构体 说明
PidControllerConfig 初始化配置，包括 kp/ki/kd、设定值、输出限幅、积分限幅、默认周期、微分滤波系数。
PidController PID 实例，保存当前配置、积分、上一拍测量值、上一拍误差、调试输出。
PidControllerDebug 调试快照，可用于串口输出曲线：p/i/d/error/integral/output/dt_s。

常用函数

函数 用途
PidController_Init() 用配置初始化一个 PID 实例。
PidController_Reset() 保留配置，清空积分、微分滤波和上一拍状态。
PidController_ComputeDt() 按指定 dt_s 计算一次 PID 输出。
PidController_Compute() 使用配置里的 default_dt_s 计算一次 PID 输出。
PidController_SetSetpoint() 运行中修改目标值。
PidController_SetGains() 运行中修改 kp/ki/kd。

3. PID 参数说明

字段 说明 建议
kp 比例系数，按当前误差直接产生输出。 先调它，让系统有基本响应。
ki 积分系数，积分项使用 error * dt_s。 用于消除稳态误差，过大会导致慢性超调。
kd 微分系数，微分项会除以 dt_s。 需要配合滤波，传感器噪声大时谨慎使用。
default_dt_s 默认控制周期，单位秒。 2ms 周期写 0.002f，10ms 周期写 0.010f。
derivative_filter_alpha 微分一阶低通系数，范围 0.0 .. 0.999。 0 不滤波，越接近 1 越平滑但滞后越大。
derivative_mode 选择对测量值微分或对误差微分。 控制执行器时推荐 PID_CONTROLLER_DERIVATIVE_ON_MEASUREMENT。
本模块的 kp/ki/kd 是直接参与计算的浮点系数，没有沿用旧 Application/pid 中“除以 1000”的历史缩放。迁移旧参数时需要重新换算或重新调参。

4. PID 使用示例

压力 PID

#include "pid_controller.h"

static PidController g_press_pid;

void PressurePid_Init(void)
{
    PidControllerConfig cfg;

    cfg.kp = 0.05f;
    cfg.ki = 0.01f;
    cfg.kd = 0.0f;
    cfg.setpoint = 25.0f;
    cfg.output_min = 0.0f;
    cfg.output_max = 255.0f;
    cfg.integral_min = -200.0f;
    cfg.integral_max = 200.0f;
    cfg.default_dt_s = 0.002f;
    cfg.derivative_filter_alpha = 0.8f;
    cfg.derivative_mode = PID_CONTROLLER_DERIVATIVE_ON_MEASUREMENT;

    PidController_Init(&g_press_pid, &cfg);
}

uint16_t PressurePid_Run(float pressure_kpa)
{
    float output = PidController_ComputeDt(&g_press_pid, pressure_kpa, 0.002f);
    return (uint16_t)output;
}

左右温控各自一个实例

static PidController g_heat_l_pid;
static PidController g_heat_r_pid;

void HeatPid_Init(float target_c)
{
    PidControllerConfig cfg;

    cfg.kp = 3.9f;
    cfg.ki = 1.8f;
    cfg.kd = 0.2f;
    cfg.setpoint = target_c;
    cfg.output_min = 0.0f;
    cfg.output_max = 1999.0f;
    cfg.integral_min = 0.0f;
    cfg.integral_max = 100000.0f;
    cfg.default_dt_s = 0.010f;
    cfg.derivative_filter_alpha = 0.7f;
    cfg.derivative_mode = PID_CONTROLLER_DERIVATIVE_ON_MEASUREMENT;

    PidController_Init(&g_heat_l_pid, &cfg);
    PidController_Init(&g_heat_r_pid, &cfg);
}

5. 滤波模块接口

头文件：Modules/Filter/target_window_filter.h

源文件：Modules/Filter/target_window_filter.c

目标窗口滤波器的规则很简单：在一段窗口内不断输入采样值，模块保存“与目标值差值绝对值最小”的那个样本。窗口结束时输出这个最佳样本。

配置项 说明
target 目标值，滤波器会选择窗口内最接近它的采样值。
sample_count_limit 样本数量窗口。为 0 时不按数量结束。
period_ms 时间窗口。为 0 时不按时间结束。

6. 滤波使用示例

100ms 内取最接近目标压力的样本

#include "target_window_filter.h"

static TargetWindowFilter g_press_filter;

void PressureFilter_Init(float target_kpa)
{
    TargetWindowFilterConfig cfg;

    cfg.target = target_kpa;
    cfg.sample_count_limit = 0;
    cfg.period_ms = 100;

    TargetWindowFilter_Init(&g_press_filter, &cfg);
}

uint8_t PressureFilter_Push(float sample_kpa, uint32_t now_ms, float *filtered_kpa)
{
    return TargetWindowFilter_Push(&g_press_filter, sample_kpa, now_ms, filtered_kpa);
}

10 个样本内取最接近温控目标的样本

static TargetWindowFilter g_temp_l_filter;

void TempFilter_Init(float target_c)
{
    TargetWindowFilterConfig cfg;

    cfg.target = target_c;
    cfg.sample_count_limit = 10;
    cfg.period_ms = 0;

    TargetWindowFilter_Init(&g_temp_l_filter, &cfg);
}

7. 在控制任务中集成

典型集成方式是在任务初始化阶段创建实例，在固定周期循环里喂数据。

void ControlTask_InitModules(void)
{
    PressurePid_Init();
    PressureFilter_Init(25.0f);
}

void ControlTask_Loop(void)
{
    float filtered_pressure;
    uint32_t now_ms = xTaskGetTickCount() * portTICK_PERIOD_MS;

    if (TargetWindowFilter_Push(&g_press_filter,
                                gSensorData.pressL,
                                now_ms,
                                &filtered_pressure))
    {
        float pwm = PidController_ComputeDt(&g_press_pid, filtered_pressure, 0.002f);
        TreatmentActuators_SetPumpPwm((uint16_t)pwm);
    }
}
如果控制闭环每一拍都必须输出，可以直接用最新测量值跑 PID；目标窗口滤波更适合用于“观测值稳定代表值”“参数学习”“显示值筛选”等场景。

8. 调参建议

  • 先只打开 kp，确认方向正确：测量值低于目标时输出应该增加。
  • 再逐步增加 ki，观察稳态误差是否减小。
  • 最后再考虑 kd，并配合 derivative_filter_alpha 抑制噪声。
  • 每个 PID 实例都要设置合适的 output_min/output_max，避免输出越过执行器能力。
  • 运行中切换治疗目标时，只调用 PidController_SetSetpoint()；如果是重新开始一段治疗，建议同时调用 PidController_Reset() 清掉历史积分。
  • 目标窗口滤波的窗口不要太长，否则会引入明显响应延迟。
